How to export your faction file from EverQuest Legends

  1. Log in to your character in EQL.
  2. In the in-game chat window, type /outputfile faction (singular faction) and press Enter.
  3. Open the folder where EverQuest Legends is installed, the folder containing the game executable, not the Logs folder.
  4. Find the newly generated text file, typically named Character_server-CLASS-Factions.txt (for example Example_qeynos-WAR-Factions.txt).
  5. Choose that TXT file below, then click Read File.

Each import automatically confirms factions at 2,000 standing and marks a faction-based race unlocked only when all its required factions are confirmed. Quest-based races remain manual. Existing confirmations are retained if faction standings later decrease. A faction export does not prove an in-game achievement was claimed, so verify race access in EQL.
